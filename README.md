Ghosting — one word describing my Wi-Fi: full bars one second, gone mid-sentence the next, no goodbye, no explanation, back again like nothing happened. A network that behaves like a bad date.

## Run it

```sh
python3 main.py
```

It writes the word to `/output/entry.txt`.
